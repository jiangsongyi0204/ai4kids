# ai4kids · AI+教育的落地实践

基于《AI时代教育全景导航》(guide.html) 的教育游戏系列。

## 🪐 写作星球 · 墨墨的灵感宇宙（`index.html`）

为 **10 岁、喜欢写作的孩子** 设计的写作冒险游戏，把 guide 中的 **「四种人」目标** 变成 4 个可以闯关的星域：

| 星域 | 对应「人」 | 关卡主题 | 核心设计（贴合 guide 心法） |
|---|---|---|---|
| 🌿 自然星域 | 自然的人 | 观察日记 / 厨房小实验 / 给大自然的悄悄话 | **先做后查**：先写观察，写完墨墨才讲科学原理 |
| 🤝 友谊星域 | 社会的人 | 换双鞋走一走 / 我帮过你你帮过我 / 如果继续冷战 | **用 AI 预演坏结局**，练习换位思考与共情 |
| 🧘 梦想星域 | 精神的人 | 梦境记录员 / 歪歪扭扭的小诗 / 深夜的一首歌 | 珍视「不完美」创作，享受独处与审美 |
| ⚙️ 未来星域 | 职业的人 | 我的AI实习生 / 故事工厂 / 小小出版人 | **把 AI 当实习生**：学「提需求」，修改 3 次以上 |

### 🤖 AI 属性（内置离线引擎，无需任何配置）
- **墨墨**：能「读」孩子写的文字，检测五感词、情绪词、比喻、对话、动词，给出 3 个个性化「闪光点」
- **苏格拉底式提问**：永远不替孩子写，只引导她深入思考（培养批判性思维）
- **灵感火花**：一键生成创作灵感
- **提需求训练**：让孩子练习给 AI 下精确指令（未来核心能力）
- **自由聊天**：和墨墨聊灵感、聊心事
- **可选真·大模型**：家长在「设置」里填入 DeepSeek 等 OpenAI 兼容 API Key 即可启用真实 AI；不填则用离线引擎，游戏始终可用

### � 部署（对齐现有 `.github/workflows/deploy.yml`，阿里云 ECS）
1. 推送 `main` 分支，GitHub Actions 自动 SSH 到服务器执行：`git pull` → `npm install` → `pm2 start npm -- run start`
2. 服务器通过 `npm start` 起 Node 静态服务，根目录入口就是 `index.html`，访问 `https://你的域名/` 直接进入游戏
3. 游戏与指南均为单文件自包含（内联 CSS/JS），无需额外构建

> 若改为部署到 GitHub Pages：把 `index.html` 推到仓库根目录，开启 **Settings → Pages**（main / root），访问 `https://<用户名>.github.io/<仓库名>/` 即可。

### 🔒 隐私与数据
- 孩子的作品、进度、聊天记录仅保存在**本机浏览器**（localStorage），不会上传
- API Key 也只保存在本机；微信内置浏览器调外部 API 可能受跨域限制，失败时会自动退回离线引擎
