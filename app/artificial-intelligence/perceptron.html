单层感知机实验室

历史上第一个会「学习」的机器

🧠 1 个神经元 ⚖️ 3 个权重 🔢 逻辑开关

🎯 实际问题：它是最简单的人工神经元

1957 年，罗森布拉特造出了「感知机」——它是第一个会「学习」的机器，就像一颗小小的神经元。它把几个信号分别乘上「权重」加在一起，超过门槛就「激活」（输出 1），否则就「睡觉」（输出 0）。今天我们来当它的教练，教它学会「与 AND」「或 OR」这样的逻辑！

输出 = 1　（当 w₁·x₁ + w₂·x₂ + b > 0）
输出 = 0　（否则）

感知机的学习法则

犯错 → 改正 · 一次只调一点点

🎯 一句话：猜错了才更新

感知机先用现在的权重算出「预测」，再和正确答案比一比。如果猜对了，什么都不用做；如果猜错了，就把权重往「正确答案」的方向推一点点，下次就更可能猜对。练得越多，分界线就越准。

📐 更新公式（三个权重一起改）

w₁ ← w₁ + η·(答案 − 预测)·x₁
w₂ ← w₂ + η·(答案 − 预测)·x₂
b ← b + η·(答案 − 预测)·1
  • η（学习率）：每步迈多大。太大容易乱跳，太小学得慢。
  • 答案 − 预测：猜对是 0（所以不更新）；猜错是 +1 或 −1（所以方向正好指向正确答案）。
  • x₁、x₂：每个输入的开关值（0 或 1），表示「这次是谁的锅」——输入是 1 的权重才需要背锅调整。

🧮 亲手算一遍（以「与 AND」为例）

输入 (1, 1)，正确答案 = 1，当前权重 w₁=0.5，w₂=−0.5，b=−0.2，学习率 η=0.4：

求和 = 0.5×1 + (−0.5)×1 + (−0.2) = −0.2 → 预测 = 0（错了！）
w₁ ← 0.5 + 0.4×(1−0)×1 = 0.9
w₂ ← −0.5 + 0.4×(1−0)×1 = −0.1
b ← −0.2 + 0.4×(1−0)×1 = 0.2

下次再看 (1, 1)：0.9 + (−0.1) + 0.2 = 1.0 > 0 → 预测 = 1 ✅ 猜对了！

⚠️ 它能学会什么？

这条法则只会画一条直线来分界，所以「与」「或」都学得会；但「异或 XOR」无论怎么调都有一条直线分不开——要学它，得等下一课的多层神经网络！
