1928

1928 年，弗兰克·罗森布拉特出生在美国。他既是一位心理学家，也是一位计算机科学家。小时候的他一定也好奇过：我们人是怎么认出东西、怎么学会新本领的呢？这份好奇，后来带他走上了一条了不起的路。

1957

1957 年，罗森布拉特造出了「感知机」——世界上第一台会「学习」的机器！它不大，看起来也不算聪明，但它做了一件全新的事：会根据经验改变自己的判断。第二年新闻一发布，全世界都轰动了。

💡 灵感

感知机的灵感来自我们的大脑。科学家发现，大脑里有一粒粒叫「神经元」的小细胞，它们互相传递信号。感知机就是照着这个模样造出来的「电子神经元」。

🎛 学习原理

它是怎么学习的呢？它先瞎猜一个答案，如果猜错了，就「拧一拧」自己内部的小旋钮（科学家叫它「权重」），多试几次，它就越猜越准。

🔁 影响至今

别小看这个「小旋钮」——今天所有 AI 的「学习」，都是从拧动这个旋钮开始的！罗森布拉特可能也没想到，他造的小机器，会种下整个 AI 学习时代的种子。

感知机的学习法则

犯错 → 改正 · 一次只调一点点

🎯 一句话：猜错了才更新

感知机先用现在的权重算出「预测」，再和正确答案比一比。如果猜对了，什么都不用做；如果猜错了，就把权重往「正确答案」的方向推一点点，下次就更可能猜对。练得越多，分界线就越准。

📐 更新公式（三个权重一起改）

w₁ ← w₁ + η·(答案 − 预测)·x₁
w₂ ← w₂ + η·(答案 − 预测)·x₂
b ← b + η·(答案 − 预测)·1
  • η（学习率）：每步迈多大。太大容易乱跳，太小学得慢。
  • 答案 − 预测：猜对是 0（所以不更新）；猜错是 +1 或 −1（所以方向正好指向正确答案）。
  • x₁、x₂：每个输入的开关值（0 或 1），表示「这次是谁的锅」——输入是 1 的权重才需要背锅调整。

🧮 亲手算一遍（以「与 AND」为例）

输入 (1, 1)，正确答案 = 1，当前权重 w₁=0.5，w₂=−0.5，b=−0.2，学习率 η=0.4：

求和 = 0.5×1 + (−0.5)×1 + (−0.2) = −0.2 → 预测 = 0（错了！）
w₁ ← 0.5 + 0.4×(1−0)×1 = 0.9
w₂ ← −0.5 + 0.4×(1−0)×1 = −0.1
b ← −0.2 + 0.4×(1−0)×1 = 0.2

下次再看 (1, 1)：0.9 + (−0.1) + 0.2 = 1.0 > 0 → 预测 = 1 ✅ 猜对了！

⚠️ 它能学会什么？

这条法则只会画一条直线来分界，所以「与」「或」都学得会；但「异或 XOR」无论怎么调都有一条直线分不开——要学它，得等下一课的多层神经网络！
